# FishPoint — projekt strony wędkarskiej

Projekt startowy strony o tematyce wędkarskiej przygotowany w folderze `strona wedkarstwo`.

## Zawartość

- `index.html` — struktura strony
- `css/style.css` — wygląd, responsywność, sekcje i kolory
- `js/main.js` — menu mobilne i przykładowa obsługa formularza
- `assets/` — miejsce na przyszłe zdjęcia, logo i grafiki

## Koncepcja

Strona jest wzorowana na układach popularnych sklepów/outdoorowych serwisów tematycznych:

- duży hero z mocnym hasłem,
- kategorie sprzętu,
- polecane zestawy,
- poradniki/blog,
- sekcja łowisk,
- kontakt/CTA.

## Jak uruchomić

Otwórz plik:

```bash
/home/baniak/strona wedkarstwo/index.html
```

albo w terminalu:

```bash
xdg-open "/home/baniak/strona wedkarstwo/index.html"
```

## Co możemy zrobić dalej

- dodać prawdziwe logo i zdjęcia,
- zrobić podstrony produktów,
- dodać blog wędkarski,
- dodać katalog łowisk,
- przerobić na sklep internetowy,
- wdrożyć stronę online.
